# docs/

| Path | What goes there |
|---|---|
| `decisions/` | Architecture decision records, `NNNN-short-title.md`. Start from `0000-template.md`. |
| `walkthroughs/` | One teaching walkthrough per phase, `phase-NN-slug.md`. Each describes the project as it was when written; they aren't rewritten when a later decision replaces something (the Phase 0 and Phase 1 walkthroughs describe the Godot client and the Go website). |
| `design/` | Design notes: protocol, movement, combat, classes, lore, threat model. |
| `ops/` | Runbooks, backups and incident notes. |
| `perf/` | Performance measurements. |
| `releases/` | Release notes, `vX.Y.Z.md`. |

Plain language, short sentences. Docs explain; the landing page sells.
