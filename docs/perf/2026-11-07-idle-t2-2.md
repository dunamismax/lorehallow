## Notes

Tier 2 is a Phase 3 target. After [ADR 0010](../decisions/0010-per-connection-memory.md), memory per connection now **passes**: 38.7 KiB against 48. Against [the run before it](2026-11-07-idle-t2.md): RSS per connection 60.3 → 38.7 KiB, heap and stacks per connection 51.1 → 25.4 KiB, mean server RSS 76.7 → 54.1 MB.

- Bandwidth (557 B/s) and CPU (12.5%) still fail for the same reason as before. Every idle bot takes one step a minute, so 1,000 of them change something almost every tick, and Phase 2 sends every change to every player in one small zone. Interest management (BUILD.md 3.3) is the fix.
- Tick p99 reads ≤ 6.40 ms against 4.53 before: one histogram bucket up (buckets are ×1.41 apart), with p50 0.57 → 0.80 ms. ADR 0010 doesn't touch the zone or its tick, and allocations per tick are unchanged (1,087 against 1,086). The generator shares the machine and decodes every message for 1,000 bots, so treat this tier's tick numbers as noisy until it runs on a separate machine.
