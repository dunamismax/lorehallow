## Notes

Case 1 Tier 1 is **not met**: memory per connection fails. Bandwidth, CPU, RTT and tick time pass.

- Before and after ADR 0008 (changed-only snapshots, batched arrivals): bandwidth 29,159 → 72 B/s per connection, CPU 4.6% → 1.5% of a core, allocations 426 → 52 per tick, RSS per connection 135 → 84 KiB. The before run is [2026-11-07-idle-t1-before.md](2026-11-07-idle-t1-before.md).
- At 100 connections the RSS delta is about 8.6 MB, so this number is noisy; the 1,000-connection run measures 60 KiB per connection.
- An exact heap profile (`GODEBUG=memprofilerate=1`, 1,000 idle connections, before the writer stopped copying prebuilt messages) showed about 26 KB of live heap per connection: net/http's 4 KiB bufio reader and writer (kept after the hijack), the session, coder/websocket's connection, the retained HTTP request and contexts. RSS is about twice the live heap because GOGC=100 lets garbage reach the live size before a collection, and idle connections allocate too little to trigger one often.
- Next: the GC settings ADR (BUILD.md 3.5, GOGC and GOMEMLIMIT), dropping the retained request, and smaller transport buffers (ADR 0007's consequences).
