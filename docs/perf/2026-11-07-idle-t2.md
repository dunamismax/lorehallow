## Notes

Tier 2 is a Phase 3 target; this is a first look. All 1,000 bots stayed connected (before batching arrivals, about half were evicted as too slow once the zone passed 256 players). Memory per connection 60 KiB (target 48), heartbeat and tick p99 pass.

- Bandwidth (557 B/s) and CPU (12.3%) fail because every idle bot takes one step a minute, so 1,000 of them change something almost every tick, and Phase 2 sends every change to every player in the one small zone. Interest management (BUILD.md 3.3) is the fix: Case 1 assumes players see few others.
- The generator ran on the same machine and decoded every message for 1,000 bots.
