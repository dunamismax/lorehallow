## Notes

Case 1 Tier 1 is **met**: every held target passes. This is the first run with memory measured as the marginal cost of a connection (scaling.md, [ADR 0010](../decisions/0010-per-connection-memory.md)): 50 bots connect, RSS is sampled for 30 s, the other 50 connect, then the main window. The repeat run is [2026-11-07-idle-t1-4.md](2026-11-07-idle-t1-4.md).

- Marginal memory 42.4 KiB per connection against 64. The old metric, (RSS − baseline) / N, reads 64.2 KiB here (72.3 in [the previous run](2026-11-07-idle-t1-2.md)), and the fixed overhead is 2.2 MB: Go's minimum GC heap goal and runtime structures, held the same with 50 or 100 players.
- Server code is the same as the previous run's (ADR 0010); only the measurement changed.
