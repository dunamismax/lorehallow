## Notes

Tier 2 is a Phase 3 target. First run with the marginal memory metric: 38.8 KiB per connection against 48, the same as the old metric (38.7), with a fixed overhead of about zero. At 1,000 connections the runtime's fixed part is lost in the noise, as the method expects.

- Bandwidth (559 B/s), CPU (12.6%) and tick p99 fail. Interest management (BUILD.md 3.3) addresses all three: Phase 2 sends every change to every player in one small zone.
- An A/B on the same machine, 1,000 idle bots and 90 s windows, run alternately twice each: the server before ADR 0010 (542cb77) measured tick p99 ≤ 4.53 and ≤ 6.40 ms, and this server ≤ 4.53 and ≤ 4.53 ms, with p50 ≤ 0.57 ms in all four. Tick p99 at this tier sits on the edge between two histogram buckets on both builds, so the 6.40 here is noise, not a regression. In the same A/B, marginal memory was 65.7 to 73.1 KiB per connection before ADR 0010 and 35.8 to 40.6 after.
