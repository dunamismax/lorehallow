# Lorehallow Pixel: the heading font for lorehallow.com, hand-drawn.
#
# Every glyph is a grid of rows: "#" is a pixel, "." is empty. Rows 1 to 7
# sit above the baseline (capital height 7); rows 8 and 9, when present,
# hang below it (descenders). A glyph with 7 rows has no descender.
# Advance width is the grid width plus one pixel of spacing.
#
# One pixel is 100 font units and the em is 10 pixels, so the font is crisp
# at font sizes that are multiples of 10px (20px = 2x, 30px = 3x).
# web/src/lib/pixelfont.ts compiles this file into a WOFF font at build time
# (internal/pixelfont) and also draws page titles on the social cards with it.
# Licensed with the rest of the art: CC BY-NC 4.0.
