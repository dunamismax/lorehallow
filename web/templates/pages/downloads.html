System requirements

  • Windows 10 or later, 64-bit; macOS 12 or later (Apple silicon or Intel); or a 64-bit Linux desktop with OpenGL 3.3.
  • Any graphics card from the last ten years. Lorehallow is 2D pixel art and runs on integrated graphics.
  • An internet connection: the world lives on the server.

Verify your download

Each file's SHA-256 checksum is listed with it. Compare it with the file you downloaded:

  • Windows (PowerShell): Get-FileHash .\file.zip -Algorithm SHA256
  • macOS: shasum -a 256 file.zip
  • Linux: sha256sum file.tar.gz

When will there be something?

Phase 2 of the plan ends with the first build anyone can download: two players in one small world, moving around and seeing each other. After that, every phase ships a new version here. Pre-1.0 versions are numbered after their phase, so Phase 2 is v0.2.0.

Builds will be free, for Windows, macOS and Linux, with a checksum for every file. A browser version comes later, in Phase 15.
